# IPTV — Ukraine

Один плоский плейлист з українськими каналами. Усе інше (97 інших країн,
генератори, дашборд, GitHub Actions) прибрано — історія лишилась у git,
за потреби файл можна дістати з попередніх комітів.

| Файл | Що це |
|---|---|
| `playlist.m3u8` | плейлист, 40 каналів, без вкладених груп |
| `lists/ukraine.md` | ті самі канали в читабельному вигляді (назва, посилання, лого, EPG id) |
| `check_channels.py` | перевірка каналів; читає `lists/`, тому список лежить саме там |

## Перевірити канали

```bash
python3 check_channels.py ukraine                       # швидко
python3 check_channels.py ukraine --confirm-dead        # + другий висновок від ffprobe
python3 check_channels.py ukraine --json check.jsonl    # результат у JSONL
```

`dead` — реально зникло. `blocked` — сервер відповів, але не пустив (так виглядає
гео-блок з-за меж України), це не поломка. `flaky` — відповідає не завжди.

Останню перевірку зроблено 2026-09-05: із 52 каналів списку 40 працюють,
12 (7 непрацюючих + 5 уже позначених мертвими) видалено.
