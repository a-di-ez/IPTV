# IPTV — Ukraine

Один плоский плейлист з українськими каналами, **136 штук**, дві групи:

| Група в плеєрі | Скільки | Що це |
|---|---|---|
| `Ukraine` | 27 | основний список, успадкований від Free-TV/IPTV і вичищений |
| `Ukraine Extra` | 109 | зібране з публічних джерел (див. нижче), тільки українськомовне |

Усе інше, що було в цьому форку (96 інших країн, генератори, дашборд,
GitHub Actions), прибрано — за потреби воно є в історії git.

| Файл | Що це |
|---|---|
| `playlist.m3u8` | плейлист, обидві групи, без вкладених файлів |
| `lists/ukraine.md`, `lists/ukraine_extra.md` | ті самі канали таблицею (назва, посилання, лого, EPG id) |
| `check_channels.py` | перевірка каналів; читає `lists/`, тому списки лежать саме там |

## Посилання для плеєра

```
https://raw.githubusercontent.com/a-di-ez/IPTV/master/playlist.m3u8
```

## Перевірити канали

```bash
python3 check_channels.py                               # обидва списки
python3 check_channels.py ukraine_extra                 # тільки один
python3 check_channels.py ukraine --confirm-dead        # + другий висновок від ffprobe
python3 check_channels.py ukraine --json check.jsonl    # результат у JSONL
```

Стани: `dead` — реально зникло. `stubbed` — сервер віддав плейлист, але всередині
заглушка замість каналу (див. нижче). `blocked` — сервер відповів, але не пустив
(так виглядає гео-блок з-за меж України), це не поломка. `flaky` — відповідає не
щоразу; майже завжди це `stream.mcquack.net`, який ріже часті запити.

### Про заглушки

`cdnua05.hls.tv` на протухлий токен відповідає не помилкою, а `200` і нормальним
маніфестом, у якому єдиний сегмент — `/stub_55x/token.ts`, картка «недоступний
токен». Перевірка заголовків бачить `#EXTM3U`, `ffprobe` декодує з картки справжнє
720p відео — обидві вважають канал живим. Через це 13 каналів роками висіли в
списку як робочі. Тому чекер тепер читає імена сегментів усередині маніфесту.

## Звідки взято `Ukraine Extra`

- [iptv-org](https://iptv-org.github.io/iptv/countries/ua.m3u) — основне джерело;
  беруться тільки фіди, які сам iptv-org позначає українською мовою (`ukr`),
  і тільки українські мовники (`*.ua`)
- [Free-TV/IPTV](https://github.com/Free-TV/IPTV) — upstream цього форку
- [myplaylists](https://myplaylists.github.io/)
- [iptv.org.ua](https://iptv.org.ua/) — звідти взято поштучно лише кілька місцевих
  мовників, яких немає деінде: решта того списку це VOD-фільми, російськомовні
  ambient-канали й ретрансляції чужих платних (Eurosport, TV1000, Amedia, Da Vinci)

Останню перевірку зроблено 2026-09-05: усі 136 каналів відповіли справжніми
сегментами, жодного мертвого чи заглушки.
